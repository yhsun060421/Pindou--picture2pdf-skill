# Changelog

## 1.0.0 — 2026-10-17

First public release.

- Image → subject cutout / chibi conversion through a user-supplied image API.
- 5×5-gridded bead discretisation with per-cell A–Z codes.
- MARD 221 standard-colour matching with CIELAB k-means + CIEDE2000.
- Vector SVG, single-page print PDF, and 1 + N page interactive PDF.
- Automatic validation: cell counts, palette sums, PDF pages and link counts.
- Zero-install interactive PDF for iPhone / iPad (Apple Books / Files).
- Claude Skill entrypoint (`SKILL.md`), reference docs and a runnable sample.
